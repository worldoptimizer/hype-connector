Connector 0.1.9

  • Ordinary folder access no longer requires writable settings or a writable lock file.
  • Removed unnecessary ownership and exact permission-mode restrictions. macOS permissions still apply.
  • Improved handling of older saved folder selections and concurrent bookmark refreshes.
  • Added a privacy-safe support report: ConnectorApp --diagnostics or connector diagnose.

App build 64 includes plugin 0.1.6 build 53. These version numbers describe separate components. Restart Connector and reconnect your MCP client after updating. If Hype already reports plugin build 53, this update does not require a plugin restart.
