Connector 0.1.11

App build 69. Hype plugin 0.1.7 build 54 is unchanged from Connector 0.1.10.

  • Setup finds Tumult Hype and installs the Connector plugin after you approve Hype’s support folder.
  • In Applications, connect Codex or Claude Code to install the local MCP connection and the bundled agent skill together. Start a new chat and use Copy first prompt to check the connection. Setup leaves the trial unstarted.
  • Connector updates unchanged skills it installed and preserves local edits. If you choose to replace an existing customized skill, Connector keeps a backup.

If Hype is already running plugin build 54, there is no need to restart it for this app update. If Setup asks for a restart, save your documents, quit Hype and reopen it.
